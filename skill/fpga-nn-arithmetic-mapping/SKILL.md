# 神经网络算术与存储的 FPGA 映射

## 输入与数值约定
取得冻结权重、算子形状、数据布局、输入范围、乘加项数、偏置、重定标、舍入及饱和规则。先明确中间结果的有符号性；位宽缩窄、重排求和和乘加融合均可能改变结果。

## 映射步骤
1. 按最坏输入与实际累加长度推导乘积和累加范围，再考虑偏置、零点修正及后续缩放。`scripts/accumulator_bound.py` 给出独立整数范围的保守有符号位宽；不是量化准确率评估器。
2. 将阵列宽度与每拍可读像素／权重同时设计。权重分银行、滑窗行缓存、同步读延迟和有效位随流水一起定义；软件多维数组不等于硬件多端口存储。
3. 用顺序读写、静态分组和唯一写入归属提高 RAM 推断可控性。若一数组需要多写端口，先检查是否能分银行或调整生产粒度，不能只加 RAM 属性便认定已映射为 BRAM。
4. 共享密集卷积与逐通道卷积的算术资源时，把供数选择、归约、结果保持和排空成本一并计算。小辅助流水是否独立，以关键等待和净资源决定。
5. 检查工具实际推断的 DSP、LUT、寄存器和 RAM。RTL 或 HLS 都须结合读写模式、位宽和调度判断，不按语言类别预设资源最省。必要的小组件核对与最终完整平台实现分层进行。
6. 对零、正负边界、最大累加、舍入临界值和代表输入验证；最终输出与冻结参考比较。功能正确、局部周期和完整物理实现分别保留证据。

```text
python scripts/accumulator_bound.py --a-min -32768 --a-max 32767 --b-min -32768 --b-max 32767 --terms 16384
```

输出数据通路、存储端口与资源净变化、数值范围和验证结果。真实映射观察见 [案例](references/case.md)；该方法可用于其他固定 CNN 和定点 DSP，不规定所有模型均采用 INT16、128 路或特定算子分工。
