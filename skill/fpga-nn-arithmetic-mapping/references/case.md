# 共享算术与存储端口的实际观察

当前 `reference/legacy_v279/tile_mac_dw4_shared_v144.v` 使用 8×16 个 DSP48E1，密集卷积与逐通道卷积共享物理乘加器；流水分开乘积与累加反馈。对有符号 INT16、16,384 项，最大正累加可达 2^44，至少需要 46 位有符号表示，现有 48 位累加器能覆盖该界。

同一源码说明：逐通道结果原来的多写数组曾被工具展开为寄存器，后来按写入归属拆为独立银行。由此抽取“先检查端口与访问方式，再判断存储推断”的步骤；不能把数组字节数直接当成 BRAM 占用。

Vivado 2026.1 完整实现使用 172/220 个 DSP，另加同规模阵列至少需 300 个 DSP；完整 RTL 对照 81,920 值零差异。本次范围脚本另验证极值与偏置边界。
