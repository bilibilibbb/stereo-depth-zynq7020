# PYNQ 神经网络张量与定点数据核对

## 输入契约
取得形状、CHW/HWC 等布局、带宽对应的打包次序、dtype 与字节序、量化尺度／零点、饱和舍入、填充、裁剪及有效掩码。PYNQ `allocate` 默认 dtype 并不是浮点；须明确设置，不能只看 Python 数值类型。

## 定位顺序
1. 从最小张量开始，分别使用单通道脉冲、通道编号、行列递增和正负边界值，先验证存储布局与流顺序，再核对模型运算。
2. 对 transpose／切片检查连续性。需要搬到 DMA 缓冲时显式复制到符合契约的连续对象；主机数组视图与设备地址的含义不同。记录这次复制的成本。
3. 用同一量化参考生成期望整数，保留缩放、舍入和饱和顺序。不要以重新自动归一化的图像验证数据；先比较原始整数、有效区域和首个差异。
4. 分别核对输入缓冲、关键算子和最终输出。若第一层即错，优先排查布局／字节序／权重次序；中途才错再查累加、重定标及边界。
5. 功能正确后再扩大图尺寸、加入双缓冲和并发；数值对照与性能计时分开。输入、期望输出、版本和契约共同保存，供新板复核。

## 工具与边界
`scripts/tensor_contract.py` 提供小张量 INT16 的 CHW/HWC 重排和逐值比较，不改量化规则。`reorder_i16` 仅排列两字节元素，不转换字节序；`compare_i16` 按明确字节序解码并限制差异示例数量。新 dtype、分组打包及亚字节数据应另加对应契约，不强行套用 INT16。

离板测试使用编号张量、反向重排、字节序错和不完整缓冲检查。真实来源与调用见 [案例](references/case.md)。
