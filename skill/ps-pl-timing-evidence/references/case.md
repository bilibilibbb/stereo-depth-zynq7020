# 真实案例

项目当前完整 RTL 回放记录 13,974,773 个周期，主机 CPU 服务时间未模拟。它用于证明一组冻结输出一致，不能换算成完整板速。

同一项目一组板端时间戳中，输入采集就绪到模型结果完成为 1,095.089 ms；之后单次按键请求到选择已有结果为 20.104 ms。前者描述处理过程，后者描述结果选择，均不包括完整传输和电脑显示时间。

核对结果：三项分别归类为功能回放、实际计算过程、请求选择，避免混用。原始出处为提交材料 evidence/complete_rtl.json、evidence/live_state.json；技能本身不依赖运行这些路径。

失败来源：历史两帧周期平均、软件 PL 夹具等待和真实任务服务混合，曾造成对完整流水速度的误判。技能验证的是证据口径，不宣称已校准所有 DDR 误差。
