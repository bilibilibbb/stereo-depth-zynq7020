# FPGA 源码与证据绑定核对

## 输入

取得当前来源清单、实际导入依赖、工具版本、原始验证回执、综合/布线报告和启动包身份。首先标明哪些文件只属于恢复基线或独立模型支线。

## 执行

1. 逐项核对影响结论的文件 SHA-256、输入及运行模式。仅以文件名或版本标签匹配不够。
2. 检查导入闭包：报告是否依赖旧 build 目录、外部 BSP、对象文件或绝对工具路径。未完成干净环境验证时如实注明。
3. 对资源注明模块范围和阶段。综合 LUT 与布线后 LUT 分开；BRAM18/36 换算时说明单位；同时检查 Slice 占用。
4. 对时序注明目标、未布局或已布线状态，并检查未约束输入、例外及 CDC。内部 WNS 为正不等于所有外部接口已签核。
5. 对正确性注明软件回放还是实际 RTL、真实或模拟 CPU、输入数量和对照值数量。局部 PASS 不自动提升为整机通过。
6. 对板端注明实际下载/启动身份、源帧与接收端版本。仅保存了打包文件或脚本退出成功，不等于已经在新电脑或板卡运行。

## 输出

生成少量结论与证据对应项：结论、文件、哈希、采集条件、适用范围、待补事项。不要为了审计建设庞大工具或重复所有仿真；只补会改变判断的缺项。

## 已验证案例与失效条件

见 [案例](references/case.md)。本技能适用于已有可读取报告；缺失日志或来源不明时只能输出未证实。它不会替代逻辑等价、时序签核、许可审核或实际换机测试。
