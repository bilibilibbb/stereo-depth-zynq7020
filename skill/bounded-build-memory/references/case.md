# 本工程观察与验证

开发过程曾因固定内存门槛和完整工具驻留受阻，之后采用动态任务树保护、单重任务、阶段化构建及受限的自有驻留处理。2026-10-31 源码重建依次完成 NN、SGM、相机、互连与完整物理实现，最终生成 BOOT.BIN；这是分阶段继续工作的实际证据，不能写成内存需求降低某个未经配对测量的百分比。

一条布线阶段记录中，工作集从 702,210,048 B 降至 17,608,704 B，私有提交却从 700,280,832 B 增至 715,497,472 B。这说明“驻留下降”不能等同于“对象或提交内存释放”。

来源：提交包 `evidence/rebuild_20261031/verification.json`、`stages/route/owned_residency.json`；源码包 `scripts/memory_guard.py`、`config/memory_policy.json`。本技能预算函数另用临界值、提交余量不足、驻留高于提交等离板用例验证。
