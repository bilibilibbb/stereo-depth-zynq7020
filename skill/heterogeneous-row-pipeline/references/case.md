# 已落地的协作结构

本工程两核通过两个行槽交接颜色处理，生产控制与消费控制分离缓存行；CPU0 生产下一行时 CPU1 消费当前行。PL 通过异步命令推进，三个完整结果槽分别承接生成、发布和发送。

该结构通过行槽及结果槽生命周期检查。固定输入同板诊断中，纯 C 单核模型与后处理约 4.74 s，双核与实际 PL 完成含 SGM 的混合处理约 0.672 s，输出逐位一致。这是整体协作诊断，不将全部时间差归因于单独的行槽改动；当前相机系统处理时间另有实测。

来源：`reference/compute/reference/v351a/r14_color_coop.c`、`r14_graph_coop.c`、`firmware/latest_pair.c`、`evidence/supplement_20261031/historical_arm/`。技能将任务对齐理解为数据就绪和可用资源的衔接，而非让两核和 PL 在同一时刻完成。
