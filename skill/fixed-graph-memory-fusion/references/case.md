# 实际存储收益与代价

本工程图内张量由 7,290,880 B 变为 1,802,240 B，减少 75.28%；属性生成与 2×2 池化融合另取消 2,621,440 B 全分辨率属性表示。包含图外工作区的完整 C 配置为 14,530,048 B → 9,061,888 B。三个统计范围不同，不相加冒充整机节省。

8 组输入、24 次配对的 1,966,080 个输出值逐位一致；电脑纯软件路径的中位时间却从 108.543 ms 变为 115.988 ms。这一反例使技能同时检查转换成本，避免把空间收益直接写成提速。

相关源码：`reference/compute/reference/v351a/r14_graph_typed.c` 与图布局文件。布局示例是缩小的教学输入，不冒充完整网络；离板测试检查最后消费者同拍覆盖、异步生命周期延长和不相交空间。
