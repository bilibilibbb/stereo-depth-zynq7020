# 固定计算图的存储压缩与融合

## 输入
取得固定图、形状、数据类型、量化规则、最终消费者和现有缓冲布局。异步 DMA、另一核心及跨帧消费者都算消费者，不能按函数返回即释放。

## 优化顺序
1. 分开列出参数、图内张量、图外工作区、DMA／结果槽和工具内存。张量字节数为元素数乘存储位宽，再计对齐、复制和缓冲深度；逻辑字节不直接等于 BRAM 数量。
2. 找最大的可删除中间表示。若下游只消费池化或归约结果，尝试按相同累加顺序直接产生所需粒度，计入边界、重复读取和新控制成本。
3. 依据最后一个实际消费者的完成事件复用空间。对跨核／DMA 保留发布、消费与归还；只读别名或原位更新须另证，不以名字不同推断互不影响。
4. 在不改已接受数值的前提下，选择定点或较窄存储；把量化转换挪到必要边界，避免每层无效往返。保留舍入、饱和、溢出和异常值处理顺序。
5. 对受影响输出做逐值对照，分别报告空间、访问和计算净变化。节约内存不自动代表 CPU 加速；完整路径出现转换成本时如实计入。

## 辅助检查
`scripts/lifetime_check.py` 接受 JSON 数组；每项含 `name, offset, bytes, birth, last_consumer`。事件区间含两端，同一最后读取事件不允许覆盖。输出地址冲突、分配跨度和存活峰值；它不生成最优布局，也不证明并发事件顺序。

```text
python scripts/lifetime_check.py references/layout_example.json
```

具体数值与反例见 [案例](references/case.md)。适用于固定 CNN、图像滤波和块处理；动态形状、原位别名和异步取消须先扩充生命周期描述。
