# 相机引脚与 CDC 来源

`pins.tcl` 保留曾取得真实双目彩条及场景数据的相机引脚布局；原文件中的历史诊断说明仍保留。`camera_cdc.tcl` 只将 BD 层级名改为本项目的 `snapshot_bd_i`，同步器数量、灰码偏斜和单一取消发起寄存器的检查保持。

这些文件目前只是待用约束源。它们没有在本候选网表上执行，也不包含真实传感器外部 setup/hold 依据。内部 8 ns 布线预算不能当作传感器输入延迟；尚不能据此宣称时序通过或生成可上板镜像。后续物理准入仍需核对实际端点、合法时钟、外部输入窗口以及当前全部资源。

历史真实采集回执也不等于本套摄像头已做标定。真实校正数据仍由相机型号、工作模式、左右身份及校准来源单独绑定。
